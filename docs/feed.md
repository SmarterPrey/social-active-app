# Feed

The feed is the Social Active App members' home — a LinkedIn-style activity stream of
posts, comments, and likes plus system posts auto-generated by the backend
(e.g. when an event video is attached).

## Data model

Vertices:

- `Member` — author of posts, comments, likes, RSVPs.
- `Post` — `{ id, body, kind: "text" | "link" | "video" | "system", mediaUrl?, createdAt }`.
- `Comment` — `{ id, body, createdAt }`.

Edges:

- `POSTED`: `Member → Post`
- `COMMENTED`: `Member → Comment`, plus `ON`: `Comment → Post`
- `LIKED`: `Member → Post` (`toggleLike` is idempotent — duplicates are
  collapsed at the Gremlin traversal source).

## Queries

- `listFeed(limit)` — top N most recent posts, projected with like count,
  comment count, and a `likedByMe` flag sourced from the caller's Cognito sub.
- `getPost(id)` — post plus threaded comments with author refs.

## Mutations

- `createPost(input)` — creates a post and the `POSTED` edge to the caller.
- `createComment(input)` — idempotent append.
- `toggleLike(postId)` — on/off; resolver returns the new `liked` state.

See [api/lambda/social.ts](../api/lambda/social.ts) for the actual traversals.
